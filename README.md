# The Wild Oasis

A hotel management dashboard built with React as part of **The Ultimate React Course by Jonas Schmedtmann**.

The application is designed for hotel employees to manage cabins, bookings, guest check-ins and check-outs, and hotel settings through a centralized dashboard.

## Features

- **Dashboard:** View hotel statistics, booking activity, sales, and stay-duration analytics.
- **Cabin Management:** Create, edit, and delete cabins.
- **Booking Management:** Browse bookings, filter and sort results, and view booking details.
- **Check-in & Check-out:** Manage guest arrivals and departures.
- **Authentication:** Restrict access to authorized employees.
- **Hotel Settings:** Configure hotel policies, including minimum and maximum stay durations and breakfast pricing.
- **Account Management:** Update user profile information and account settings.
- **Dark Mode:** Switch between light and dark themes.

## Tech Stack

- **React** — Component-based user interface.
- **React Router** — Client-side routing and navigation.
- **TanStack Query (React Query)** — Server-state management, caching, and data synchronization.
- **Supabase** — Database, authentication, and backend services.
- **Styled Components** — Component-based styling.
- **React Hook Form** — Form management.
- **Recharts** — Data visualization and analytics.
- **React Hot Toast** — User feedback and notifications.
- **date-fns** — Date manipulation and formatting.
- **Vite** — Development server and build tooling.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- A Supabase project

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd the-wild-oasis
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your Supabase credentials using the environment variable names expected by your project.

5. Start the development server:

   ```bash
   npm run dev
   ```

Open the local URL displayed in your terminal to access the application.
